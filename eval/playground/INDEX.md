## 列说明

- naive：朴素做法得到的数是否等于 naive.expectedRows（ok = 陷阱复现；FAIL = 陷阱没有复现）。`—` 表示未声明。
- 停机信号：正确交互之后页面状态是否符合 stopSignal。
- 陷阱：`verified` 表示 runner 复现了陷阱；`missing` 表示没有复现；`vitest` 表示由 vitest 核验（runner 不计入判定）；`none` 表示没有声明陷阱。
- 状态：`oracle-verified` 表示本次 oracle 判定全部通过；`oracle-failed` 表示有未通过项。
- 产品：case.json 的 `product`，产品（检测 / 选表）在这个 case 上的结果，由括号里写的单测给出（red / green / known-gap）；oracle 不判定它。`—` 表示未登记。
