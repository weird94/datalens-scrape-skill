# datalens-scrape

[English](README.md) | 中文

一个免费的网页采集 skill，给 Claude Code 等 AI agent 用：你说想要页面上的哪些数据，它把整份列表采下来存成 CSV，分页、无限滚动、「加载更多」都能处理。

- **免费**：不用注册、不用 API key、不按条收费。
- **复用你的登录**：网站拦机器人或要登录时，可以在你自己的 Chrome 里采，用你已有的登录状态（会先问你）。
- **纯本地，保护隐私**：浏览器和脚本都在你的电脑上跑，中间没有采集服务或代理。cookie 不出你的电脑，页面内容只交给你本来就在用的 agent，CSV 只存在本地。
- **整份采全，如实报告**：分页、无限滚动、「加载更多」、「展开回复」由脚本处理，每次都报告是怎么停的，不会把采了一半的结果当成全部。
- **任何网站，不靠模板**：agent 每次现场看页面、重新写配置，不局限于支持列表里的平台，网站改版也能应对。
- **准确率有核对**：10 个真实网站上由另一个 agent 逐字段核对，9 个全对，1 个错了 3 格（结果见下文）。

```
你：把这篇新闻下面的评论都导出成 CSV，回复也要 https://news.qq.com/rain/a/...
agent：已保存 comments.csv，共 160 行（主评论 123 + 回复 37），9 列：
       nickname、reply_to、is_reply、content、picture、sticker、likes、location、location_date。
       「加载更多」一直点到没有，每条回复都展开了。
```

适合的内容：搜索结果、商品列表、评论和回复、榜单、名录、表格。不会去破验证码或机器人验证。

## 安装

**Claude Code 一步装好**（需要 Claude Code 2.1.275 或以上）：

```
/plugin install datalens-scrape --marketplace weird94/scrape-skill
```

**任何 agent**：把这句话发给它：

```text
帮我把 https://github.com/weird94/scrape-skill 里的 skill（在 skill/ 目录）装上，装完试一下能不能用。
```

需要 Node.js 18 或以上。第一次运行会给 Playwright 下载一次 Chromium。

目前只在 Claude Code 里测过。skill 本身就是 SKILL.md 加 Node 脚本，别的能加载 skill 的 agent 理论上也能用，但还没测过。

## 怎么用

装好后直接跟 agent 说要什么，带上网址：

- 「把这个搜索结果前 5 页的商品采下来，要标题、价格、店铺、链接：<url>」
- 「这个榜单全部导出成表格：<url>」
- 「这篇文章的参考文献整理成 CSV：<url>」
- 「采 100 条评论就行：<url>」

agent 会先看一眼页面，确定哪一块是你要的列表、每行读哪些字段、下一页怎么来，先试采两页检查，没问题再采全部。最后告诉你：

- 文件存在哪、多少行、有哪些列；
- **怎么停的**：真的到底了、采到你要的数量了、撞上页数上限（会明说「还没采完」）、页面写的总数和采到的对不上，或者被网站拦了；
- 哪些字段缺了、为什么。

没指定字段时它会把每行能看到的信息都采上，包括每行自己的链接。说清楚「要哪几列」「要多少条」结果会更贴近你要的。

## 网站拦住了怎么办

skill 默认在后台开一个看不见的浏览器。很多网站会拦这种浏览器，有些内容要登录才看得到。这时 agent 会**先问你**，同意后改用你自己的 Chrome 来采，带着你的登录状态。

第一次要做的准备：按 [Playwright Chrome Extension 的设置文档](https://github.com/microsoft/playwright/tree/main/packages/extension#readme) 装好扩展。只需要装扩展，文档里配置 MCP 服务器那一步不用做。

采的过程中：

- 不要动那个正在被操作的标签页；
- **别把 Chrome 窗口最小化或被别的窗口完全挡住**，不然页面不渲染、滚动和加载都会卡住，脚本会停下提示你；
- 碰到验证码或登录页，agent 不会替你处理，你在那个标签页里自己过一下，它再继续。

连不上时的报错和处理办法见 [`skill/references/browser.md`](skill/references/browser.md)。

## 在哪些网站上试过

2026 年 11 月测过，每个站都由另一个 agent 自己打开页面、逐字段核对：

| 网站 | 采的内容 | 结果 |
|---|---|---|
| Hacker News | 首页前 3 页 | 90 行，全对 |
| 豆瓣电影 Top250 | 全部 | 250 行，全对 |
| 百度热搜 | 全部 | 51 行，全对 |
| YouTube | 搜索结果 | 100 行，全对（自动排除了 Shorts 和广告） |
| YouTube | 视频评论 | 50 行，全对 |
| Nature | 文章参考文献 | 62 行，全对 |
| 腾讯新闻 | 文章评论（含回复） | 160 行，全对 |
| Google Play | 应用评论 | 50 行，全对 |
| Spotify | 专辑曲目 | 84 行，全对 |
| 维基百科 | 「最大公司」营收表 | 50 行，合并单元格那两行错了 3 格 |

**要用你自己的 Chrome 才能采**：Reddit、Product Hunt（各试过一次，都采到了）。Udemy、同花顺、雪球也会拦后台浏览器，在自己的 Chrome 里能打开，但还没完整采过。

网站改版后选择器可能失效。agent 每次都是现场看页面、重新写配置，不依赖存好的模板，所以一般不受影响；如果你发现哪个站采得不对，欢迎提 issue。

## 用什么模型

Opus 和 Sonnet 测下来效果最好。Haiku 也能用，在上面 10 个站上 7 个全对、3 个差一点，差在两种地方：

- 容易提前收工，比如只采了一部分就说完成了；
- 数据分散在页面的其他视图或标签页里时，它不太会主动去找。

用小模型时，留意它报告里的「怎么停的」：写着「还没采完」或者总数对不上，就让它接着采。

## 还不支持

- 逐行点进详情页采数据（只采列表本身能看到的内容）
- iframe 里的列表
- 某些嵌入式评论组件（closed shadow root）
- 点下载按钮才拿到的文件
- CSV 以外的输出格式

## 数据去了哪里

脚本只在你的电脑上跑，只依赖 Playwright，不调用任何模型或外部服务。页面内容只交给你正在用的 agent，CSV 存在你指定的位置。skill 要求 agent 把页面文字只当数据：页面里如果写着让它做什么，它会告诉你，而不是照做。

## 常见问题

**怎么用 Claude Code 采集网页数据？**
装上这个 skill，然后用大白话说要什么、带上网址，比如「把这个页面的评论全部导出成 CSV：<url>」。agent 会自己找列表、定字段、搞清楚怎么翻页，再用 Playwright 在你的电脑上采。

**要 API key 或者付费账号吗？**
不要。Apify、Firecrawl 这类云端采集 skill 需要 API key，按请求或按条收费。这个是在本地开浏览器，不用注册任何东西。

**要登录才能看的页面能采吗？**
能。经你同意后它会改用你自己的 Chrome，用你已经登录的状态。验证码它不会替你过。

**无限滚动、分页、「加载更多」能处理吗？**
能。滚动和点击由脚本完成，报告里会写明是怎么停的，你能知道是不是采全了。

**它是爬虫吗？**
不是。它只采你给的那个网址上的一份列表（包括所有分页），不会顺着链接把整个网站爬一遍。

## 更喜欢点鼠标？试试 DataLens

这个 skill 出自 [DataLens](https://datalens.uk/zh?utm_source=github&utm_medium=readme&utm_campaign=scrape-skill)，一个 Chrome 插件，不用 agent 也能做同样的事：打开页面、点几下，把列表导出成 CSV 或 Excel。只想要数据、不想写提示词的时候更顺手。
